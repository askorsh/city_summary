# City Summary

CLI-утилита для получения сводки по городу.

Программа получает данные из внешних API:

- погода — Open-Meteo;
- курс валюты к рублю — Frankfurter.

## Возможности

- получение текущей погоды по городу;
- получение курса валюты к RUB;
- обработка данных по заданным правилам;
- вывод результата в обычном формате;
- вывод результата в JSON;
- обработка ошибок внешних сервисов;
- повторные запросы при временных ошибках.

## Установка

Создать виртуальное окружение:

```bash
python3 -m venv .venv
Активировать виртуальное окружение:
source .venv/bin/activate

Установить зависимости:
python -m pip install -r requirements.txt


Запуск со значением по умолчанию:

python main.py


Указать город:

python main.py --city Paris

Указать город и валюту:

python main.py --city Paris --currency EUR


Вынести результат в JSON:
python main.py --city Moscow --currency USD --json

Правила обработки:

если температура ниже 0 °C, устанавливается warm_clothes: true;
если курс валюты выше 100 RUB, устанавливается expensive: true.


Коды завершения
0 — успешное выполнение;
2 — ошибка аргументов командной строки;
3 — город или валюта не найдены;
4 — внешний сервис недоступен после повторных попыток.
